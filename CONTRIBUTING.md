# Contributing to CodeHydra

We love your help! To keep things smooth:

1. **Fork** the repo.
2. **Create a branch** for your fix/feature.
3. **Run tests** using `uv run pytest`.
4. **Submit a PR** with a clear description of the change.

## Security
Do **NOT** commit your `.env` files or session tokens. CodeHydra is designed to scavenge these locally; they should never leave your machine.
